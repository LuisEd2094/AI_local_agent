   Use this when the user wants to **explain**, **document**, **write a README**, **describe**, or **summarise** code.
   Parameters:
   - source: "file", "git_diff", or "folder"
   - filepath: (required if source is "file") – the file to document
   - folderpath: (required if source is "folder") – the folder/directory to document

- If the user asks to document, explain, or write a README for a specific file (e.g., "main.py", "src/app.js"), you MUST respond with:
  {"action": "generate_readme", "parameters": {"source": "file", "filepath": "the_filename"}}

  {"action": "generate_readme", "parameters": {"source": "folder", "folderpath": "the_folder"}}

  {"action": "generate_readme", "parameters": {"source": "git_diff"}}
